Find anything UXDuck can do by typing its name. The common ones have shortcuts.

## Find any action

Type `>` in the input to list every action with its shortcut. Keep typing to narrow it, for example `>vehicle`, and press **Enter** to run the first. Without `>`, actions appear among the other results. Asking the agent from this input is available only in development and staging builds while the in-app AI chat is hidden in production.

## Shortcuts

| Action                   | macOS | Windows and Linux |
| ------------------------ | ----- | ----------------- |
| Focus the input          | ⌘K    | Ctrl+K            |
| Show or hide the sidebar | ⌘B    | Ctrl+B            |
| Send feedback            | ⌥B    | Alt+B             |
| Open the Map tab         | ⌥M    | Alt+M             |
| Open the Telemetry tab   | ⌥V    | Alt+V             |
| Back                     | ⌘[    | Alt+←             |
| Forward                  | ⌘]    | Alt+→             |

Shortcuts with ⌥ (Alt) follow the key's place on the keyboard, whatever character it types. They do not run while you type in other fields, except ⌘K. There are none on touch screens; use `>` in the input instead.

## Change a shortcut

1. Open **Settings › Keyboard**.
2. Choose an action's shortcut, then press the new keys. Hold ⌘, ⌃ or ⌥ (Ctrl or Alt) with the key.
3. **Clear** removes it, **Reset** puts it back, and **Reset all shortcuts** puts them all back.

Your shortcuts work in every window. Where two actions share a key, Settings says which one runs; UXDuck's own shortcut wins.
