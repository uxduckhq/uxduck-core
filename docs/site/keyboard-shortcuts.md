Find anything UXDuck can do by typing its name. The common ones have shortcuts.

## Find any action

Type `>` in the input to list every action with its shortcut. Keep typing to narrow it, for example `>vehicle`, and press **Enter** to run the first. Without `>`, actions appear among the other results. Asking the agent from this input is available only in development and staging builds while the in-app AI chat is hidden in production.

## Shortcuts

| Action                   | macOS | Windows and Linux |
| ------------------------ | ----- | ----------------- |
| Open the command palette | ⌘K    | Ctrl+K            |
| Open Settings            | ⌘,    | Ctrl+,            |
| Show or hide the sidebar | ⌘B    | Ctrl+B            |
| Show or hide Home        | ⌥H    | Alt+H             |
| Show or hide Fleet       | ⌥⇧V   | Alt+Shift+V       |
| Show or hide Places      | ⌥P    | Alt+P             |
| Send feedback            | ⌥B    | Alt+B             |
| Open the Map tab         | ⌥M    | Alt+M             |
| Open the Telemetry tab   | ⌥T    | Alt+T             |
| Back                     | ⌘[    | Alt+←             |
| Forward                  | ⌘]    | Alt+→             |

Shortcuts with ⌥ (Alt) follow the key's place on the keyboard, whatever character it types. Most actions leave text fields alone; Settings, the command palette, the sidebar, Home, Fleet and Places also work while typing. There are none on touch screens; use `>` in the input instead.

## Desktop window shortcuts

| Action       | macOS | Windows and Linux |
| ------------ | ----- | ----------------- |
| New Window   | ⇧⌘N   | Ctrl+Shift+N      |
| Close window | ⌘W    | Ctrl+W            |
| Quit UXDuck  | ⌘Q    | Ctrl+Q            |
| Full screen  | ⌃⌘F   | F11               |

Settings is also in the **UXDuck** menu on macOS and **File** on Windows and Linux. Opening Settings keeps your workspace behind it; pressing its shortcut again leaves Settings open. Its native menu follows changes you make to the shortcut. **File › New Window** opens another view of the same UXDuck. Closing a window leaves UXDuck running; the quit shortcut asks before stopping it.

The desktop app's Edit, View and Window menus provide the standard editing, zoom and window controls for your platform.

## Change a shortcut

1. Open **Settings › Keyboard & approvals**.
2. Choose an action's shortcut, then press the new keys. Hold ⌘, ⌃ or ⌥ (Ctrl or Alt) with the key.
3. **Clear** removes it, **Reset** puts it back, and **Reset all shortcuts** puts them all back.

Your shortcuts work in every window. Where two actions share a key, Settings says which one runs; UXDuck's own shortcut wins.
