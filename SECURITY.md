# Security

Please report a vulnerability privately, never in a public issue or pull request.

- **On GitHub:** open this repository's **Security** tab and choose
  **Report a vulnerability**.
- **By email:** write to security@uxduck.com.

Include what is affected, how to reproduce it and the UXDuck version
(`uxduck --version`). We reply within a few working days and keep you updated
until it is fixed. Fixes ship in the next release, and we credit you in the
advisory unless you ask us not to.

Only the latest release receives security fixes.
