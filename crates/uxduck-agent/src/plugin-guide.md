Authoring reference (TypeScript, ABI 2):

- Supply the whole ES module as `script`. Only `@uxduck/sdk` imports are available; no fetch, filesystem, DOM, Node modules or other files. Handlers return Effects synchronously.
- Start with `read`. Read actual telemetry keys with telemetry_get before subscribing. `subscribe.items = { keys: ["battery.remaining_pct"], cadenceMs: 1000 }` delivers the latest item of each subscribed key per vehicle. Missing values need a guard; retain earlier values in a Map if a calculation needs several keys across batches.
- `onItems(batch)` receives `{ items: [{ vehicleId, key, unit, value?, text?, timeUs }] }`. Import `latest` and `value` from `@uxduck/sdk`. Example: `const i = latest(batch, id, "battery.remaining_pct"); return i?.value == null ? {} : { items: [value(id, "battery_watch.remaining_pct", "Battery", "percent", i.value)] };`.
- `describe()` returns `{ panels: [{ id: "main", title: "Battery", tab: true, vehicle: true, widgets: [{ type: "value", item: "battery_watch.remaining_pct", label: "Battery" }] }] }`. `vehicle: true` follows the selected vehicle and supports pinning. Omit it for independent tools; emit their items with `value(null, ...)`.
- An item key is `group.name`, lower case with underscores. Numeric units require suffixes: meter `_m`, second `_s`, percent `_pct`, time `_at` (Unix seconds), volt `_v`, ampere `_a`. Unitless text uses no unit suffix. Helpers: value, text, table, latest, notify, point, circle, commandLong. Map coordinates in GeoJSON are [longitude, latitude]; point/circle helper arguments are latitude, longitude. Feature ids must be unique per vehicle when showing a fleet.
- `onMessages({ messages, gap })` receives decoded MAVLink fields in raw MAVLink units; declare message names in `subscribe.messages`. `onFrames({ frames, gap })` receives base64 payloads; declare numeric ids in `subscribe.frames`. Handle a gap as dropped data.
- `onStart({ stored, nowMs })` restores persisted state. Return `{ store: { key: value } }` to save; null deletes a key. Total storage is 64 KiB. `onTick({ nowMs })` runs at `subscribe.tickMs` (minimum 100 ms), or once after an effect's `wakeInMs`. Prefer a wake-up and `ratePerS` on readouts to polling. Date.now() and nowMs are milliseconds; item timeUs is microseconds.
- Declare every command in `commands` with name, title, description, risk and optional JSON Schema parameters. `onCommand({ command, vehicleId?, params })` receives it. Independent tabs have no vehicleId; check before commanding a vehicle. Outbound vehicle commands still require the corresponding capability and normal operator approvals.
- Draft, run plugin_test, inspect error, flightS, calls and actual items, then revise. Zero flightS or no on_items/on_messages calls does not verify telemetry behavior. Replay does not send commands or enforce all engine permissions. Install only when requested, using the returned path; the operator approves.
